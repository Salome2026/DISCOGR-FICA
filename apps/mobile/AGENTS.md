# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Pinned to SDK 54 deliberately (not the latest) — the App Store's Expo Go build only supports SDK 54 while Apple's review of the SDK 57 update is pending. Don't bump past 54 without checking Expo Go's current App Store SDK support first, or `npx expo start` will fail on real devices with "Project is incompatible with this version of Expo Go."
